= Contributing to xcikit

== Build

The default build command is `./build.sh`. It uses Conan to download dependencies, builds the project, runs tests, installs the release artifacts to `artifacts/`.

See `README.adoc` for more detailed instructions.

== Submitting issues or pull requests

Be brief and concise. If it's a bug, provide a minimal repro.
